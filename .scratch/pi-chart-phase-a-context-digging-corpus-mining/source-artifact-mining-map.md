## Scope and authority

This artifact mines Phase A source intent only. Brownfield implementation and patient corpus evidence are intentionally recorded as `not-covered` unless a source-control artifact names the later reconciliation surface. The map does not promote any source proposal into accepted v0.5 design by itself.

Authority interpretation:

- Phase A control docs define the method and limits: `clinical function → minimum data → provenance → lifecycle → pi-chart slot`, primitive discipline, canonical/derived/rendered separation, and open-question surfacing.
- A0a through A9b source artifacts are clinical/function intent evidence and schema-slot pressure, not implementation authority.
- `OPEN-SCHEMA-QUESTIONS.md` is the durable open-schema register; its triage states are preserved below instead of flattened.
- `phase-a-status-matrix.md` confirms the role of each Phase A artifact and warns that A3-A9b source inputs are not silently implementation-ready.
