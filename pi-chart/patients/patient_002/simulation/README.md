# patient_002 simulation/evaluation layers

This directory is retained for live-demo staging and evaluation material from patient_002_chart_v4.zip. It is not part of ordinary pi-chart chart-visible state.

- `latent_release/`: staged provider/non-RN chart releases after demo start.
- `live_expected/`: evaluator reference for expected live RN/pi-agent charting.
- `reference_completed_chart/`: retrospective reference only.

Hidden physiology truth from the zip is intentionally not stored here. It is owned by pi-sim under `../pi-sim/vitals/scenarios/patient_002_septic_shock_recovery.scripted.json`.
